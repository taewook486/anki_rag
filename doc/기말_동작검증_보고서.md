## 1. 그룹 1-1 — Q&A 무에러 반복 동작

### 1.1 진입점 3종 동작 확인

| 진입점 | 명령/엔드포인트 | 결과 | 비고 |
|--------|----------------|------|------|
| CLI | `python -m src chat` | 정상 (반복 루프) | `while True` + Ctrl+C 종료, 대화 히스토리 최대 10쌍 유지 |
| CLI | `python -m src query "질문"` | 정상 | 1회 질의응답 |
| CLI | `python -m src search "키워드"` | 정상 | 단순 하이브리드 검색 |
| FastAPI | `POST /api/query` | HTTP 200 | RAG 응답 + sources |
| FastAPI | `POST /api/adaptive` | HTTP 200 | 3-전략 자동 분기 |
| Streamlit | http://127.0.0.1:8501 | HTTP 200 | 4탭 UI (검색/채팅/그래프/관리) |

### 1.2 반복 입출력 동작 (`chat` 명령)

`src/__main__.py` 의 `chat()` 함수 구현:

```python
while True:
    question = click.prompt("\n질문")
    answer = rag.query(question, history=history)
    click.echo(f"\n답변:\n{answer}")
    history.append({"role": "user", "content": question})
    history.append({"role": "assistant", "content": answer})
    if len(history) > _CHAT_MAX_HISTORY_TURNS * 2:
        history = history[-(_CHAT_MAX_HISTORY_TURNS * 2):]
```

- 무한 루프로 반복 입출력 보장
- KeyboardInterrupt (Ctrl+C) 시 정상 종료
- 대화 히스토리는 최근 10쌍만 슬라이딩 윈도우로 유지

### 1.3 에러 처리

| 시나리오 | 응답 |
|---------|------|
| 빈 질문 입력 | Pydantic `Field(min_length=1)` 가 거부 → HTTP 422 |
| LLM API throttle | `except Exception` 잡아 HTTP 500 + 한국어 에러 메시지 |
| Qdrant 동시 접근 | "Storage folder ... already accessed" 에러 (로컬 모드 한계) |
| 존재하지 않는 단어 | 정상 응답 + "검색된 자료에 없습니다" (1-3절 참조) |

## 2. 그룹 1-2 — 참조 출처 출력

### 2.1 sources 필드 스키마 (전 엔드포인트 공통)

```typescript
interface SourceInfo {
  word: string;    // 검색된 단어 (예: "abandon")
  source: string;  // 원본 파일 식별자 (예: "toefl_voca_v1")
  deck: string;    // Anki 덱 이름 (예: "TOEFL 영단어")
}
```

### 2.2 실측 응답 샘플

**입력**: `{"question":"abandon meaning","top_k":3}`

**`POST /api/query` 응답 sources**:
```json
[
  {"word": "abandon",     "source": "--forvo-youglish_link", "deck": "해커스-초록이"},
  {"word": "abandonment", "source": "toefl_voca_v1",         "deck": "TOEFL 영단어"}
]
```

### 2.3 채점 기준 충족 여부

| 기준 | 충족 |
|------|------|
| 참조의 내용은 반드시 구분되어 검색 가능한 형태 | ✅ 단어/소스/덱 3-필드로 분리 |
| 참조 문서(파일명 및 부분 내용) 출력 | ✅ source = 원본 .apkg 파일명, deck = 사용자 친화 덱명, word = 인용된 단어 |
| 결과 형태(콘솔/Web UI) 자유 | ✅ CLI는 텍스트, FastAPI는 JSON, Streamlit은 표 UI |

## 3. 그룹 1-3 — 의도 결과 (할루시네이션 방어)

### 3.1 방어 메커니즘 3단계

1. **검색 단계 필터**: RRF 점수 0.005 미만 결과 제외 (`src/rag.py:21`)
2. **컨텍스트 빌드 단계 필터**: 전체 컨텍스트 2,000자, 예문 150자 상한
3. **LLM 프롬프트 가드**: SYSTEM_PROMPT에 "검색 결과에 없는 내용은 답변하지 말 것" 지시

### 3.2 엣지 케이스 검증

**테스트 1 — 존재하지 않는 단어**

입력:
```json
{"question": "quibblesnark meaning", "top_k": 3}
```

응답:
```
검색된 자료에 없습니다.

"quibblesnark"라는 단어는 제공된 참고 자료에 존재하지 않습니다.

---

다만, 참고 자료에서 유사한 단어는 찾을 수 있습니다:

quibble [/ˈkwɪbəl/]
뜻: 둔사(핑계)하다, 모호한 말을 하다, 익살부리다; 생트집을 잡다
출처: 편입 영단어 2022 (xfer_voca_2022)
```

판정:
- "검색된 자료에 없습니다" 명시 → 할루시네이션 회피 ✅
- 유사 단어 `quibble`을 출처와 함께 안내 → 가산점 요소 (사용성)
- sources 필드에도 `quibble`만 포함되어 응답 본문과 일관성 유지

**테스트 2 — 부분 매칭만 있는 질의**

입력:
```json
{"question": "give up과 유사한 구동사"}
```

응답 말미에 LLM이 자발적으로 출력한 한계 명시:
```
⚠️ 참고 자료에 수록된 구동사가 제한적이므로,
추가적인 유사 구동사(e.g. quit, stop, abandon)는 검색된 자료에 없습니다.
```

판정: SYSTEM_PROMPT 가드가 실제 응답에 그대로 반영됨을 입증.

## 5. Adaptive RAG 3-전략 분기 검증

### 5.1 Simple 전략 (Dense only)

입력: `{"question":"abandon meaning","use_graph":false}`

응답 메타:
```json
{"complexity":"simple","strategy_used":"dense_only","graph_used":false,"graph_terms":[]}
```

### 5.2 Complex 전략 (Agent ReAct + GraphRAG Fusion)

입력: `{"question":"비즈니스에서 계약 해지 관련 단어를 난이도 순으로 정리해줘","use_graph":true}`

응답 메타:
```json
{"complexity":"complex","strategy_used":"agent_react","graph_used":true,"total_agent_steps":3}
```

Agent ReAct 트레이스 (응답 내 `agent_steps`):

| 스텝 | thought | tool | args |
|-----|---------|------|------|
| 1 | 비즈니스에서 계약 해지 관련 단어들을 검색해보겠습니다 | search_word | `{"query":"계약 해지 terminate cancel contract","top_k":10}` |
| 2 | 더 많은 계약 해지 관련 단어들을 검색해보겠습니다 | search_word | `{"query":"contract termination cancellation rescind void annul breach","top_k":15}` |
| 3 | (finish) | — | — |

각 스텝의 `observation`에는 RRF 점수와 함께 인출된 단어가 포함되어 추론 과정을 추적할 수 있다.

## 7. 알려진 한계 및 운영 시 주의

1. **Qdrant 로컬 모드 동시 접근 불가**: CLI와 FastAPI는 동시에 같은 `qdrant_data` 디렉터리를 열 수 없다. 시연 시 한 가지 모드만 활성화하고 시연.
2. **BGE-M3 콜드 스타트**: 첫 호출 시 모델 로딩 약 30~45초. 시연 직전 워밍업 권장 (`curl /api/query` 1회 사전 호출).
3. **LLM API rate limit**: claude-sonnet-4-6 Tier 1 신규 계정은 분당 호출 제한. 시연 전 사용량 확인.
